# Cinefy

Cinefy is a BookMyShow-style movie ticket booking backend system built using Java, Spring Boot, and MySQL.

## Planned Features
- User Authentication
- Movie Management
- Theater & Screen Management
- Seat Booking
- Payment Handling
- Booking Cancellation
- Seat Locking

## Tech Stack
- Java 21
- Spring Boot
- MySQL
- Spring Data JPA
- Hibernate
- REST APIs
